# Dataverse Patterns & Learnings

Reference for current and future Dataverse work in Playbook Agent.

## SDK Access Pattern (PAC CLI Code Apps)

The PAC CLI generates typed services in `PlaybookAgent/src/generated/`:
- **Models** (`models/*.ts`): TypeScript interfaces for each entity
- **Services** (`services/*.ts`): Static classes with `create`, `update`, `delete`, `get`, `getAll`, `getMetadata`

All services use `getClient(dataSourcesInfo)` from `@microsoft/power-apps/data`. Auth is handled by the Power Apps host — no tokens, no fetch, no axios.

## Generated Service API

```typescript
// List with structured options (NOT raw query strings)
Service.getAll({ top: 10, filter: "name eq 'Test'", select: ['name', 'teamid'], orderBy: ['name asc'] })

// Get by ID
Service.get(id, { select: ['name'] })

// Create — Omit the primary key (auto-generated)
Service.create({ name: 'Test', 'LookupField@odata.bind': '/tablename(guid)' })

// Update — Partial fields
Service.update(id, { name: 'Updated' })

// Delete
Service.delete(id)

// Metadata
Service.getMetadata()
```

## Lookup Binding

Dataverse lookups require `@odata.bind` format:
```typescript
// Helper in sdk.ts:
lookupBind('systemusers', 'abc-123')  // → "/systemusers(abc-123)"

// Usage:
TeamsService.create({
  name: 'My Team',
  'BusinessUnitId@odata.bind': lookupBind('businessunits', buId),
  'AdministratorId@odata.bind': lookupBind('systemusers', userId),
  teamtype: 0,
  membershiptype: 0,
})
```

## OData Filter Escaping

Always escape single quotes in user-provided filter values:
```typescript
escapeOData("O'Brien")  // → "O''Brien"
```

## Active-Version Semantics

For config-like entities, only read active records:
```typescript
filter: "statecode eq 0"
```

## Adding a New Table

When a new table is added via PAC CLI:

1. Run `pac code add` for the new table
2. Register in `sdk.ts` TABLES constant:
   ```typescript
   jw_agent: { name: 'jw_agents', primaryKey: 'jw_agentid' }
   ```
3. Add traced CRUD wrappers in `dataverse.ts`
4. Add hook functions in `useDataverse.ts`
5. Register in DataverseExplorer AVAILABLE_TABLES
6. Update CLAUDE.md data model section

## Response Shape

`IOperationResult<T>` has:
- `data: T` — the typed result
- Other platform metadata

For lists: `IOperationResult<T[]>` where `data` is the array of records.

## Known Gotchas

- `orderBy` must be an array of strings: `['name asc']`, not a raw string
- `filter` is a raw OData string — caller must escape values
- `TeamsBase` requires `teamtype` and `membershiptype` as numeric keys (0, 1, 2, 3)
- `create` omits the primary key field (it's auto-generated by Dataverse)
- Connector responses are wrapped variably — always normalize via `normalizeConnectorResponse()`
